# Ashford & Vale | Counsel of Consequence ⚖️

**Discretion. Precision. Conviction.**

Ashford & Vale is a premium web platform designed for an elite, global corporate law firm. Established with a dark, sophisticated aesthetic, the site reflects the firm's legacy of representing the world's most consequential institutions. The user interface is engineered to convey trust, authority, and exclusivity.

## ✨ Key Features

* **Premium UI/UX:** A sophisticated dark theme with gold/copper accents, utilizing elegant typography to establish a high-end corporate identity.
* **Practice Area Showcases:** Detailed, interactive grids displaying core legal disciplines (Corporate & M&A, Private Wealth, Litigation, Capital Markets, IP, and Regulatory).
* **Track Record Highlights:** Impactful data presentation sections emphasizing key firm metrics ($48B+ Transactions, 97% Favorable Outcomes).
* **Partner Profiles:** A dedicated executive section featuring high-resolution, monochrome portraiture of the firm's leadership to build immediate trust.
* **Responsive Design:** Flawless execution across desktop, tablet, and mobile viewing environments.

## 🛠️ Tech Stack

* **Framework:** React / TanStack Start
* **Build Tool:** Vite
* **Styling:** Tailwind CSS

## 🚀 Getting Started

To run this project locally on your machine, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine. This project uses **Bun** as the package manager.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/bacuuyyy/ashford-and-vale-website.git](https://github.com/bacuuyyy/ashford-and-vale-website.git)

2. Navigate into the project directory:
   ```bash
   cd ashford-and-vale-website

3. Install the dependencies:
   ```bash
   bun install

4. Start the development server:
   ```bash
   bun run dev

Open http://localhost:5173 (or the specific port shown in your terminal) with your browser to see the result.
